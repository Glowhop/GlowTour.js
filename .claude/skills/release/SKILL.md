# Release

Use this skill before shipping or preparing a release.

## Rules

- Confirm the release scope and user-visible impact.
- Check tests, documentation, migration notes, security implications, and operational readiness.
- Keep changelog entries factual and scoped.
- Identify rollout risks and rollback expectations.
- Do not bypass failing validation without explicit acceptance and a documented risk.

## Output

- State readiness status.
- List blockers.
- List validation performed or still required.
