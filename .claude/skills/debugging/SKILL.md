# Debugging

Use this skill before changing code to fix a bug.

## Rules

- Reproduce the failure or state why reproduction is incomplete.
- Gather evidence before proposing a fix.
- Form one hypothesis at a time.
- Verify the hypothesis with the smallest useful check.
- Identify the owning layer before editing: frontend, backend, test, configuration, data, environment, security, or performance.
- Do not stack speculative fixes.

## Output

- State reproduction steps.
- State root cause or remaining hypotheses.
- State the targeted fix owner.
- State the retest needed to prove the issue is resolved.
