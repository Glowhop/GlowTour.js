Glow Tour is a cross-framework guided-tour library that works with React, Vue, Solid, Angular, and vanilla JavaScript. Create interactive product tours, onboarding flows, and feature highlights with a simple, composable API.

## Get started

- **[Getting Started](/docs/getting-started)** — Install Glow Tour and build your first tour in minutes.

## Choose your framework

Select your framework to learn framework-specific setup, APIs, and patterns:

- **[React](/docs/guides/react)** — React components and hooks
- **[Vue](/docs/guides/vue)** — Vue components and composition API
- **[Solid](/docs/guides/solid)** — Solid components and signals
- **[Angular](/docs/guides/angular)** — Angular components and dependency injection
- **[Vanilla](/docs/guides/vanilla)** — Custom elements and plain JavaScript
